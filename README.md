# Tetris

A simple Tetris game built from scratch using C# and WPF.

## Technologies

* C#
* WPF
* XAML
* Object-Oriented Programming

## Features

* Seven standard Tetris block types
* Block movement and rotation
* Collision detection
* Automatic block placement
* Row clearing
* Score tracking
* Game-over detection
* Next-block queue

## Structure

The game logic is separated into different classes for blocks, the game grid, game state, positions, and block management.

Different block types inherit from a common `Block` base class.
